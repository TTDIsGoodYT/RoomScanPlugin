# RoomScanPlugin

A quick template for a room scanning plugin, useful if you have a Neocities site for a DOORS game.

## How to use

### Set-Up

- Python
  * Open the script
  * Change the Neocities username to yours (the bit before `.neocities.org`)
  * Change the Neocities password to yours
- Lua
  * Open the script
  * Change the total rooms number to your number (e.g. `total = 100`)
- JavaScript
  * Put it in your Neocities site.

## What this adds

- A button in the Plugins tab
- Automated progress tracking

## Requirements

- A progress bar
- A progress section
