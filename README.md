# RoomScanPlugin
A quick template for a room scanning plugin, useful for if you have a neocities site for a doors game.
## How to use
- Python
  * Open the script
  * Change the Neocities username to yours (the bit before .neocities.org)
  * Change the Neocities password to yours
- Lua
  * Open the script
  * Change to total rooms number to your number (eg. total = 100)
